# 🕷️ چت‌روم چندنفره

این پروژه یک چت‌روم واقعی چندنفره با Node.js و Socket.IO است.

## 1. نصب Node.js

نسخه LTS را از سایت رسمی Node.js نصب کن.

بعد از نصب، در CMD یا PowerShell این دو دستور را بزن:

node -v
npm -v

## 2. نصب پروژه

داخل پوشه پروژه:

npm install

## 3. اجرای سرور

npm start

باید چیزی شبیه این ببینی:

Chat server running at http://localhost:3000

## 4. تست روی کامپیوتر خودت

مرورگر را باز کن و برو به:

http://localhost:3000

برای تست چندنفره، چند تب باز کن.

## 5. چت با دوستان از دستگاه‌های دیگر

برای اینکه دوست‌هایت از اینترنت وارد شوند، سرور Node.js باید روی یک سرور/هاست عمومی اجرا شود.

بعد از Deploy شدن، آدرس عمومی مثل:

https://your-chat.example.com

را برای دوستانت می‌فرستی.

## نکته مهم

این نسخه پیام‌ها را فعلاً فقط در RAM سرور نگه می‌دارد.
اگر سرور خاموش یا Restart شود، تاریخچه پیام‌ها پاک می‌شود.

برای نسخه جدی‌تر می‌توانیم بعداً:
- ثبت‌نام و ورود کاربر
- رمز عبور
- اتاق‌های مختلف
- ذخیره دائمی پیام‌ها با SQLite/PostgreSQL
- ارسال عکس و فایل
- پیام خصوصی
- لیست کاربران آنلاین
- مدیر و اخراج کاربر
- لینک دعوت خصوصی

را اضافه کنیم.
